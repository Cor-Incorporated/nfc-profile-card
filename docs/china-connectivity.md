# 中国向け接続調査（2026-09-06）

- Vercel公式: 中国本土の到達性保証なし。独自ドメイン推奨、外部依存削減。https://vercel.com/kb/guide/accessing-vercel-hosted-sites-from-mainland-china
- 実構成: www.tapforge.org 独自ドメインあり。Cloudflare経由の応答を現接続で観測。中国本土の非VPN回線による実測ではない。
- 公開プロフィールはサーバー側Firestore取得、フォントはnext/fontで自己配信。ログイン前の閲覧は認証完了を待たない。
- OCR: クライアントから同一オリジンAPIへ送信、VercelからGeminiへ接続。ただしGoogle OAuth・Firebase Auth・Firestoreのブラウザ通信は残る。
- Gemini利用地域: 中国本土は提供リストにない。APIクライアントの利用者への提供地域にも規約の制約がある。サーバーを海外に置くだけで中国利用を保証しない。https://ai.google.dev/gemini-api/docs/available-regions https://ai.google.dev/gemini-api/terms
- 即時対策: 公開連絡先をvCard QRとして端末へ保存。QR読取側はWebアクセス不要。中国での相手端末の連絡先認識は実機確認が必要。
- 中国向けオンラインOCRを提供するには、利用可能なOCRサービスと認証・保存経路を別途検証する必要がある。

## オフライン名刺交換

公開プロフィールのQRボタンで「連絡先・通信不要」を選び、QR画像を端末へ保存する。
連絡先ファイルも同じ画面から保存できる。画面を開く最初の通信は必要だが、保存済み画像の
読み取りにはTapForge・Googleへのアクセスは不要。プロフィール変更後は再保存する。
写真はQRに含めない。カスタムプロフィールは表示中のプロフィール1件とリンクだけを使い、
非表示のアカウント情報で補完しない。複数のプロフィールがある場合は対象を推測しない。

## 検査

- ローカルの実Chromeで公開プロフィール→QR切替→PNG・VCFダウンロードを操作。
- ダウンロードしたPNGを独立したzxing-cppで復号し、VCFとバイト一致。
- VCFをvobjectで解析し、表示名、2件の電話、WeChatの保持と構文を確認。
- 390×844表示でQR・保存操作が収まることを画面確認。端末実機の検査ではない。
- 氏名の推測分割なし、特殊文字・UTF-8折り返し・カスタムプロフィール選択のJest 3件通過。
- 本番OCRは新キー・新モデル指定で再デプロイ後、ユーザーから実操作成功の報告あり。
- 中国本土のVPNなし回線と相手のカメラアプリでの動作は未確認。これを中国対応完了とは扱わない。
